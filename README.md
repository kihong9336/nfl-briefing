# NFL 브리핑 — 스포츠 뉴스룸 MVP

49ers, Chiefs, Patriots 팬을 우선하는 한국어 NFL 해설 아카이브입니다. 매일 오전 8시(KST)에 새 브리핑을 발행합니다.

## 현재 구현

- 상단 날짜 레일과 달력 입력
- 날짜별 고정 URL 쿼리 (`?date=YYYY-MM-DD`)
- 전체 / 49ers / Chiefs 필터
- 리그 핵심 뉴스, 팀 포커스, 해설, 관전 포인트
- 공식 하이라이트 영역
- 다가오는 경기 보드
- 모바일 390px 대응
- 샘플 데이터임을 명시하는 안전 배너

## 실행

```bash
npm test
npm run serve
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 데이터 구조

현재 샘플 데이터는 `src/data.js`에 있습니다. 실제 운영 시 매일 검증된 브리핑을 같은 구조의 JSON으로 생성한 뒤 정적 사이트 빌드 또는 API 저장소에 추가합니다.

권장 운영 흐름:

1. 매일 웹 검색 및 공식 출처 교차 검증
2. 구조화된 브리핑 JSON 생성
3. 날짜별 데이터 파일 저장
4. 사이트 재배포
5. Telegram에는 제목·핵심 3줄·해당 날짜 URL만 전송

## 배포 전 남은 결정

- 서비스 이름과 도메인
- 공개 사이트 여부
- 호스팅: Cloudflare Pages 또는 Vercel
- 브리핑 데이터 저장: 저장소 JSON 또는 관리형 DB

실제 뉴스 데이터는 아직 연결하지 않았으며, 화면의 모든 기사 문구는 디자인 검증용 샘플입니다.
