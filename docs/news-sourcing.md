# NFL 뉴스 수집·편집 범위

## 리그 전체를 먼저 조사

관심 팀 기사부터 채우지 않는다. 최근 24~36시간을 기준으로 NFL 공식 뉴스와 ESPN, AP Sports, CBS Sports NFL, NBC Sports/ProFootballTalk, Yahoo Sports NFL을 탐색한다. 이들 중 최소 네 개의 서로 다른 뉴스 조직에 실제 접근을 시도하고 결과를 기록한다. 같은 통신사 기사를 재배포한 여러 사이트는 독립된 검증으로 세지 않는다.

그 후 49ers·Chiefs·Patriots 공식 발표 및 담당 기자 원문을 심화 조사한다. 리그 주요 사건은 해당 구단·NFL 원문으로 교차 확인하되, 공식 사이트에 없다는 이유만으로 신뢰할 만한 기명 취재 보도를 배제하지 않는다. 취재 보도와 공식 확정을 구분한다.

## 검색 범위

- 경기 결과·승부를 가른 변화·다음 주요 매치업
- 부상·출전 상태·로스터 변동
- 트레이드·계약·징계·리그 정책
- 순위 경쟁·기록·전술 변화와 직접 관련된 확인된 새 사실

부상 보고서만 반복 검색하지 않는다. 후보를 모은 뒤 최근 7일 발행본과 사건 단위로 대조한다. 제외한 기사 수를 새 기사로 억지로 채우지 않되, 첫 후보군이 중복이면 다른 매체/주제로 2차 탐색을 한다. 모든 팀 매일 한 건 같은 분량 할당은 없다.

## 내부 감사 파일

`.incoming/YYYY-MM-DD.audit.json`은 비공개 수집 기록이다. 공개 저장소에 추가하지 않는다.

```json
{
  "date": "YYYY-MM-DD",
  "coverage": [
    {"name": "매체", "domain": "매체 호스트", "status": "retrieved", "url": "https://실제로-열어본-주소", "checkedAt": "실제 ISO 시각", "note": "원문 확인 결과 및 범위"}
  ],
  "candidates": []
}
```

접근 실패는 `blocked` 또는 `failed`와 실제 사유로 기록한다. 검색 스니펫만 읽은 것은 원문 조회 성공이 아니다. 이 기록은 에이전트의 수행 기록이며 사실관계 검증을 대신하지 않는다.

`node scripts/check-source-coverage.mjs .incoming/YYYY-MM-DD.audit.json --date YYYY-MM-DD`를 발행 전에 실행한다. 좁은 매체만 조사했거나 날짜/형식이 잘못된 감사 기록이면 발행하지 않는다. 네 뉴스 조직에 시도했더라도 원문 조회 성공이 두 조직 미만이면 `partial`: 브리핑 설명에 일부 출처 접근 제한을 명시하고 리그 전체를 조사했다고 표현하지 않는다.

## 새 발행본의 YouTube 영상 정책

하이라이트와 선택 항목인 `tactic.video`는 직접 재생할 HTTPS YouTube 영상만 사용한다. 허용 형식은 `youtube.com`·`www.youtube.com`·`m.youtube.com`의 `/watch?v=영상ID` 또는 `/shorts/영상ID`, 그리고 `youtu.be/영상ID`이며 ID는 영문·숫자·밑줄·하이픈 11자다. 채널·검색·플레이리스트 주소와 유사 도메인은 허용하지 않는다.

수집/cron 단계에서 실제 원본 영상을 열어 제목·채널 및 내용의 적합성을 확인한다. 발행기의 URL 형식 검사는 영상 존재 여부나 공식 채널 여부를 검증하지 않는다. 대체 영상 URL을 추측하지 않는다.

확인된 YouTube 영상이 없으면 NFL·구단 공식 웹사이트 영상으로 대체하지 않는다. 새 발행기는 입력을 복제한 뒤 해당 하이라이트 또는 전술의 영상 항목만 생략하고 제목을 포함한 `Video unavailable` 경고를 출력한다(URL·인증 정보는 출력하지 않는다). 전술 설명·뉴스·취재 출처는 보존하며 선택 영상의 부재만으로 뉴스 발행을 차단하지 않는다. 이 정책은 새 발행에만 적용하고 과거 데이터와 렌더링은 변경하지 않는다.

## 기사 선정

인기·검색 노출 순서를 중요도와 혼동하지 않는다. 리그 영향, 확인된 새 변화, 관심 팀과의 관련성을 함께 판단한다. 발행 최소 기사 수는 없으며, 중요한 소식을 기존 4건 제한에 맞추어 잘라내지 않는다. 중복 제거 후에도 조사 범위가 충분한지 확인한다. 사건별 eventKey와 실제 변화 근거는 기존 publication guard 기준을 따른다.

오늘의 짧은 브리핑에는 주요 제목을 배치하고, 선정된 기사는 하단 리그/관심 팀에서 다시 표시하지 않는다. 전술 교실은 새로운 사례·해설 근거가 있을 때 게재하며 같은 설명을 매일 재발행하지 않는다.
